Tax Breakdown & Fee Separation

MoSPI CPI Index Methodology: AirIndex India strips out non-base tax fluctuations (UDF, GST, fuel surcharge) to measure pure airline fare inflation. Only the Base Fare component (68%) feeds the Laspeyres index calculation. Tax components are tracked separately for regulatory transparency.

  • Residential IP rotation & request header randomization.
